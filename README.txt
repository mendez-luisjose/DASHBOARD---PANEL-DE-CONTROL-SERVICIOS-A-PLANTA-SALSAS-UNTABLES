- config.js

- aire_fallback.js
- nh3_fallback.js
- ptab_fallback.js
- ptar_fallback.js
- vapor_fallback.js
- suav_fallback.js

La carpeta apps_script_backend es solo de referencia para Apps Script; no es necesaria para que GitHub Pages muestre el dashboard.

Después de subir a GitHub:
1. Commit changes.
2. Espere la publicación de GitHub Pages.
3. Abra el dashboard con Ctrl+F5.
4. Puede abrir diagnostico_drive.html para probar la conexión con Apps Script.

IMPORTANTE:
Si el /exec funciona solo cuando hay una sesión Google iniciada pero falla en incógnito u otro dispositivo, el problema es del acceso/despliegue de Apps Script y no de estos archivos de GitHub.
